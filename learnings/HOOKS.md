# Test a different reason to watch

Choose three distinct promises, such as:
- Result: start with the useful outcome.
- Recognition: name a problem the viewer already has.
- Mechanism: open with the surprising explanation or process.

A thesis-first opening can work well for an opinion, but it is a hypothesis,
not a universal rule. Only make claims the actual take supports.
For an argument, try: thesis, familiar belief, why it is incomplete, mechanism,
concrete proof, payoff, return to the opening. Skip steps that do not serve the take.

Decide what the test changes. Overlay-only variants keep the same approved body.
If the participant asks for genuinely different spoken openings, propose source
reorders, document them and get approval. Do not label three text changes as
three structural edits. Record results before turning a preference into a rule.
