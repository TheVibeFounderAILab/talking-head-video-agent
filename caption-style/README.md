# Portable single-word captions

One spoken word, uppercase white, centered, zero tracking. No background,
stroke, emoji or colored emphasis. A rare two-word semantic unit is allowed.
Use exact word timestamps after remapping the edit. Keep source punctuation in
the transcript; hide terminal punctuation only in the displayed token.

Anton is a portable open-source substitute for the private custom caption face.
It is distributed under the included SIL Open Font License. This is not a
pixel-identical export of the private preset. Preview the longest words at a
shared size (112px starting point) and check contrast and face separation.

CSS paths resolve from this file. If copying it into another composition,
copy the font too and update the relative URL. Do not use a CDN during rendering.
