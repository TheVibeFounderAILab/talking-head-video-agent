# Before sharing a project

This workshop starter was built from an allowlist of reusable instructions,
fresh templates and portable helper code. It includes no creator footage,
private transcripts, analytics, client projects, account credentials or history.
The exact private custom font is excluded; Anton and its OFL license are bundled.

Your own working folder will become private as you use it. Before sharing it:
- Remove input media, transcripts, work outputs, private captions and QA screenshots.
- Remove .env files, tokens, cookies, credentials, session exports and local paths.
- Remove .git, agent histories, cache folders, editor state and symlinks.
- Inspect filenames, metadata, ZIP contents and all documents manually.
- Only distribute media, fonts and third-party assets you have rights to share.

The included .gitignore helps prevent accidental commits; it is not a privacy
audit. Only input/README.md, work/README.md and final/README.md are starter files.
Helper scripts do not call a network service. A coding agent or optional ASR
provider may process your data remotely. Review its settings before using
sensitive material. No automatic publication or cloud upload belongs in this kit.
