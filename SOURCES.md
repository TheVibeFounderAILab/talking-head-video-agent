# Sources and adaptation

TheVibeFounder Talking Head Video Editor workflow, project template, active
short-form rules, opinion-editing lessons and caption conventions informed this
workshop edition. The instructions were rewritten to be participant-neutral;
private project examples, source footage, transcripts, analytics and personal
paths were not copied. The helper code and example templates were authored for
this portable edition.

Public tooling references checked October 15, 2026:
- HyperFrames: https://hyperframes.heygen.com/quickstart
- FFmpeg: https://ffmpeg.org/download.html
- Python: https://www.python.org/downloads/
- Anton font and license: https://github.com/google/fonts/tree/main/ofl/anton

Do not infer permanent platform safe zones or guaranteed performance from the
workshop's conservative layout and editorial defaults.
